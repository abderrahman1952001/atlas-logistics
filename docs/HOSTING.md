# Hosting assessment

Checked 29 October 2026 against the providers' own documentation. No account or paid service was created for this implementation. The existing fast Atlas stays the main live demo; this implementation is runnable locally and in CI.

| Service                                                                                      | Verified free offer and limits                                                                                                                                                                                                       | Decision                                                                                                                            |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| [Neon](https://neon.com/pricing)                                                             | No credit card or time limit; 100 CU-hours monthly and 1 GB storage per project; compute scales to zero after five idle minutes.                                                                                                     | Suitable optional hosted PostgreSQL for a later demo. No database created.                                                          |
| [Render](https://render.com/docs/free)                                                       | Free web services sleep after 15 idle minutes; wake-up takes about a minute. Free PostgreSQL expires after 30 days and is deleted after the additional grace period if not upgraded. Free web services have ephemeral local storage. | Do not use its temporary database for durable proof. Optional web hosting only after reviewing current limits and billing settings. |
| [Koyeb](https://www.koyeb.com/docs/faqs/pricing)                                             | Free web instance exists, but signup requires a card with a $29 preauthorization; plan selection can incur a charge. [Free instances](https://www.koyeb.com/docs/reference/instances) sleep after one idle hour.                     | Not selected for the no-card/no-cost path.                                                                                          |
| [GitHub Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions) | Standard GitHub-hosted runners in public repositories are free. Larger runners and storage are separate considerations.                                                                                                              | Standard Ubuntu runner; no artifact upload or cache storage; bounded 15-minute workflow.                                            |

`docker compose up --build -d` is the primary reproduction path and does not depend on any of those hosting providers. Provider plans can change; recheck before signup. Real production use needs an availability, backup and capacity plan and may have costs.
